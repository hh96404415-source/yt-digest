# YT 摘要

YouTube 頻道更新自動摘要的**唯讀網頁版**——通勤時打開就能看文字重點，不用看影片。

## 這是什麼

- 自動監控指定的 YouTube 頻道，有新影片就抓字幕、用 AI 整理出「主旨／重點／結論」
- 這個網站的資料來自 `summary.json`（由自動流程定期匯出）
- 純靜態頁面：開啟快、不用登入、任何裝置都能看

## 功能

- 按**內容分類**篩選（模型/工具測評、應用/教學、科技新聞/趨勢、軍事/時事、生活/其他）
- 點標題才展開重點，平時一眼看到多條題目
- 日期排序（最新在最上面）
- 「已讀」只記在這台裝置（localStorage），不會影響其他人
